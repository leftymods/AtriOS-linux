# MainlineAtriOS

MainlineAtriOS — Linux-прошивка и набор системных сервисов для **AtriStation**, модифицированной Яндекс Станции Макс **YNDX-0053 MAX**.

Целевая аппаратная версия AtriStation использует **Amlogic S905X3 (`sm1`) вместо S905X2**. Профиль `station-max` и его загрузочные образы предназначены для варианта с S905X3.

## Возможности

- Mainline Linux и Mainline U-Boot.
- Обработка звука с микрофонного массива: выбор микрофонов, эхоподавление и шумоподавление.
- Локальные голосовые команды и опциональный HTTPS-ассистент.
- Воспроизведение музыки и Bluetooth A2DP.
- Подписанные OTA-обновления с проверкой целостности и откатом.
- Системные службы на Rust и C; Python для работы колонки не требуется.

## Устройство

Сейчас основной профиль — `station-max` для AtriStation YNDX-0053 MAX на **S905X3**. Шаблон `template` предназначен для портирования и сам по себе не означает поддержку готовой платы.

Подробности по аппаратной модификации и состоянию поддержки: [DEVICES.md](DEVICES.md). Состояние драйверов: [DRIVERS.md](DRIVERS.md). История изменений: [CHANGELOG.md](CHANGELOG.md).

## Сборка и проверка

Команды запускаются из корня репозитория в Linux или WSL.

```bash
# Доступные профили
./compile.sh list

# Параметры целевой платы
./compile.sh info BOARD=station-max

# Образ для AtriStation на S905X3
./compile.sh BOARD=station-max RELEASE=Nebula TARGET=image

# Тесты и проверки репозитория
make test
make verify
```

Профили платы находятся в `config/boards/`, конфигурация ядра и файлы платы — в `board/yandex/station2/`.
