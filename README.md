# AtriOS Control (Android Material 3)

Официальное Android-приложение для управления умными колонками на базе **AtriOS Nebula** в стиле **Material 3 (Material You)**.

Приложение работает напрямую с колонкой по **Bluetooth RFCOMM SPP** (канал `1`, UUID `00001101-0000-1000-8000-00805F9B34FB`) через демон `/usr/lib/atrios/bt-control` — интернет и облако не требуются.

---

## Возможности

- **Material 3 / Material You:** динамические цвета системы на Android 12+ (`dynamicLightColorScheme` / `dynamicDarkColorScheme`), светлая и тёмная темы, карточки, чипы и слайдеры Material 3.
- **Живая телеметрия колонки:** модель и ОС (`AtriOS Nebula`), версия ядра, температура CPU, оперативная память, датчик освещённости (`lux`), статус Wi-Fi и IP-адрес.
- **Аудио:** плавное управление громкостью (`0–100%`) с синхронизацией с энкодером и AVRCP, кнопка `Без звука`, тестовый аудиосигнал.
- **LED-экран `25×16` и RGB-кольцо:** переключение режимов (`Часы`, `Kisser`, `Глаза`, `Бегущая строка`, `Выкл`) и режимов верхнего кольца (`Радуга`, `Громкость`, `Выкл`).
- **Bluetooth-приватность:**
  - отображение текущего статуса видимости (`Скрыта (PSCAN)` или `Видима`),
  - список сопряжённых устройств с возможностью удаления конкретного MAC-адреса,
  - кнопка **«Сопряжение 60 с»** (временно открывает видимость колонки для добавления нового устройства, после чего колонка снова скрывает свой идентификатор) и кнопка **«Скрыть»**.
- **Настройка Wi-Fi:** передача SSID и пароля на колонку прямо по Bluetooth.

## Протокол обмена (Bluetooth RFCOMM SPP)

Соединение устанавливается с сопряжённым устройством по стандартному SPP UUID `00001101-0000-1000-8000-00805F9B34FB`. Сообщения передаются построчно в формате JSON (`\n`-разделитель):

| Команда | Параметры | Назначение |
|---|---|---|
| `get_status` | — | Запрос полной телеметрии и статуса Bluetooth |
| `set_volume` | `volume` (`0..100`) | Установка громкости |
| `set_mute` | `mute` (`true`/`false`) | Включение/выключение звука |
| `audio_test` | — | Воспроизведение тестового сигнала |
| `set_screen` | `mode` (`clock` \| `kisser` \| `eyes` \| `ticker` \| `off`), `state`, `text` | Управление фронтальным экраном `25×16` |
| `set_ring` | `mode` (`rainbow` \| `volume` \| `off`) | Управление верхним RGB-кольцом |
| `bt_pair` | `seconds` (`10..300`) | Открыть окно видимости для нового сопряжения |
| `bt_hide` | — | Немедленно скрыть идентификатор (`PSCAN`) |
| `bt_unpair` | `mac` (или `"all"`) | Удалить сопряжённое устройство |
| `wifi_connect` | `ssid`, `psk` | Подключить колонку к Wi-Fi |
| `reboot` | — | Перезагрузка колонки |

## Сборка APK

1. Клонируйте ветку `app`:
   ```bash
   git clone -b app https://github.com/leftymods/AtriOS-linux.git AtriOS-App
   ```
2. Откройте папку `AtriOS-App` в **Android Studio** (AGP `8.5.2`, Kotlin `2.0.20`, `compileSdk = 34`, `minSdk = 26`).
3. Выполните **Build → Build Bundle(s) / APK(s) → Build APK(s)** или через Gradle:
   ```bash
   ./gradlew assembleDebug
   ```

## Разрешения Android

- `BLUETOOTH_CONNECT`, `BLUETOOTH_SCAN` (Android 12+)
- `BLUETOOTH`, `BLUETOOTH_ADMIN` (Android 8–11)
