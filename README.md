# AtriOS Control (Android Material 3)

Официальное Android-приложение для управления умными колонками на базе открытого мульти-модельного фреймворка **AtriOS** в стиле **Material 3 (Material You)**.

Приложение работает напрямую с колонкой по **Bluetooth RFCOMM SPP** (канал `1`, UUID `00001101-0000-1000-8000-00805F9B34FB`) через демон `bt-control` — интернет и облако не требуются.

---

## Возможности

- **Поддержка нескольких колонок (Multi-Speaker):** сохранение подключённых колонок AtriOS (модель, кодовое имя, версия прошивки, MAC), быстрое переключение между колонками и автоматическая адаптация UI под аппаратные возможности устройства (LED-матрица, RGB-кольцо, датчик освещённости, BT-колонка, локальный ИИ).
- **Обновление прошивки (OTA) с телефона:** просмотр текущей версии, кнопка проверки обновлений, отображение новой версии, размера и списка изменений (changelog), прогресс загрузки/проверки/установки, статус и ручной/автоматический откат (rollback).
- **Яндекс Музыка напрямую на колонке:** авторизация через Яндекс OAuth с автоизвлечением `access_token` и локальным сохранением на колонке (`0600`), запуск «Моей волны», «Любимых треков», поиск по трекам/исполнителям, управление воспроизведением (Play/Pause, Next, Prev, Like, Dislike, Stop).
- **Таймеры и будильники:** просмотр активных таймеров с оставшимся временем, быстрые пресеты (`1–30 мин`) и произвольное время, добавление и удаление будильников.
- **ИИ-ассистент и Qwen3-TTS:** включение/выключение ассистента, выбор режима (`Локальный офлайн мини-AI` / `GPU-сервер` / `Гибрид`), адрес сервера, слово активации, выбор голоса и эмоции Qwen3-TTS (`neutral`, `happy`, `sad`, `serious`, `whisper`, `shout`, `angry`, `excited`, `surprised`).
- **Время (NTP) и часовой пояс:** синхронизация времени по NTP и выбор часового пояса (включая синхронизацию с часовым поясом телефона в одно нажатие).
- **Аудио и LED:** громкость (`0–100%`), `Без звука`, тестовый сигнал, режимы фронтального LED-экрана (`Часы`, `Kisser`, `Глаза`, `Бегущая строка`, `Выкл`) и верхнего RGB-кольца (`Радуга`, `Громкость`, `Янтарный`, `Синий`, `Зелёный`, `Красный`, `Выкл`).
- **Bluetooth-колонка и приватность:** переключатель режима Bluetooth-колонки (A2DP), статус видимости (`Скрыта (PSCAN)` / `Видима`), управление списком сопряжённых устройств, окно сопряжения (`120 с`) и кнопка «Скрыть».
- **Wi-Fi и система:** подключение колонки к Wi-Fi по Bluetooth, телеметрия (CPU, ОЗУ, ядро, lux, аптайм) и перезагрузка.

## Протокол обмена (Bluetooth RFCOMM SPP)

Сообщения передаются построчно в формате JSON (`\n`-разделитель):

| Команда | Параметры | Назначение |
|---|---|---|
| `get_status` | — | Запрос полной телеметрии, статуса BT, AI и OTA |
| `ota_status` | — | Текущее состояние OTA и доступность отката |
| `ota_check` | — | Неблокирующая проверка обновлений |
| `ota_apply` | `reboot` (`true`/`false`) | Запуск загрузки, проверки и установки OTA |
| `ota_rollback` | `reboot` (`true`/`false`) | Откат к резервной копии предыдущей прошивки |
| `ymusic_status` / `ymusic_login` / `ymusic_logout` | `token` (OAuth) | Авторизация и статус Яндекс Музыки на колонке |
| `ymusic_play` / `ymusic_control` | `mode` (`wave`\|`likes`\|`search`), `query`, `action` | Воспроизведение и управление треками Яндекс Музыки |
| `get_timers` / `set_timer` / `cancel_timers` | `secs` (`1..86400`), опц. `id` | Управление таймерами |
| `get_alarms` / `set_alarm` / `cancel_alarms` | `hour`, `minute`, `enabled`, опц. `id` | Управление будильниками |
| `ntp_sync` / `set_timezone` | `tz` (IANA, напр. `Europe/Moscow`) | Синхронизация NTP и часовой пояс |
| `set_ai` | `enabled`, `mode`, `server`, `wake_word`, `tts_voice`, `tts_emotion` | Настройка локального/удалённого ИИ и Qwen3-TTS |
| `set_volume` / `set_mute` / `audio_test` | `volume` (`0..100`), `mute` | Управление аудио |
| `set_screen` / `set_ring` | `mode`, `state`, `text` | Управление LED-матрицей и RGB-кольцом |
| `bt_speaker` / `bt_pair` / `bt_hide` / `bt_unpair` | `enabled`, `seconds`, `mac` | Режим BT-колонки и приватность |
| `wifi_connect` / `reboot` | `ssid`, `psk` | Подключение Wi-Fi и перезагрузка |

## Сборка APK

```bash
git clone -b app https://github.com/leftymods/AtriOS-linux.git AtriOS-App
cd AtriOS-App
./gradlew assembleDebug
```
(Требуется JDK 17+, Android SDK 34, AGP `8.5.2`, Kotlin `2.0.20`.)
